# Hand-off, 29 October 2026

State of the `feature/kyc-only-replicas` branch after this session, for whoever continues the work. Read this first, then the doc linked from each section.

## Ground rules (from the project owner)

- **Never** push to `main`, merge into `main` or open a PR unless the owner asks. Commit only when asked.
- Secrets and machine-local data are git-ignored and must never be committed: `backend/.secrets/`, `data/issuer_keys/`, `data/generated/`, `models/`, `precomputed/`, `backend/trueid.db`, `backend/uploads/`, `clients/*/.env.local`.
- Ask before large design changes.

## What the branch contains

`main` was merged into this branch (main's motion liveness and RBI V-CIP extras, commit `167d586`), then the work below was added on top.

### 1. Partner KYC sites that call TrueID server to server
Three demo partner sites under `clients/`: Tideway (Zerodha-style, :3011), Meridian (HDFC InstaAccount-style, :3012) and Kestrel (home loan, :3013). Partner API at `/api/partner/v1/*` with an `X-Partner-Key`. Guide: `docs/PARTNER_INTEGRATION.md`; check a connection with `python scripts/check_partner_connection.py`.

### 2. Cross-institution fraud network (consortium)
Banks share keyed HMAC hashes of identifiers, never customer data. A conflict holds a case for review (`EV_NETWORK_FAIL`), but never approves or rejects on its own. Code: `backend/app/consortium.py`, client `scripts/consortium_client.py`, tests `backend/tests/test_consortium.py`.

### 3. Analyst console redesign ("Evidence Desk")
- **Look:** Bricolage Grotesque for display, Geist for UI, Geist Mono for data. A warm lab-grey ground, ink structure and one ultramarine accent (#2B3BE6). Decision colours are green #0F7B52, amber #B4690E and vermilion #C8361F. Tokens live in `frontend/app/globals.css`; shared components in `frontend/components/ui.tsx`.
- **Case page** (`app/dashboard/case/[id]/page.tsx`): verdict header with risk ring and stamp, six clickable check cards, a "Do the sources agree?" grid, required evidence as "X of 13 passed" with failures first, tabs (Overview / Document / Face & liveness / Linked applications / Session), and a sticky decision panel with summary and audit trail.
- **Queue:** riskiest first, risk-spine case files, pattern chips. **Evaluation:** a plain-language headline and five tabs.
- **Design boards:** a Claude Design canvas artifact (private to the owner): https://claude.ai/artifact/4Aows8CHEdnx2BT2xLEGFN

### 4. Governed self-learning loop: `docs/LEARNING_LOOP.md`
- **Stages:** Collect (analyst decisions only) → Monitor (PSI drift, check health) → Propose (band recalibration, retrained challenger, advisories) → Govern (analyst approves, audited, one-click rollback).
- **Code and screen:** `backend/app/learning.py`; page `/dashboard/learning`.
- **Applicant tips:** fixable issues only, never fraud signals. They appear on the applicant result page (`coaching` field), on Kestrel's review screen, and in the partner verdict (`applicant_coaching`).

### 5. Analytics assistant: `docs/ASSISTANT.md`
- **Where:** a floating **Ask TrueID** button (bottom right, Ctrl + /) with a side panel that knows the current page and case. The Investigator page (`/dashboard/chat`) continues the same conversation.
- **How it answers:** from live facts (totals, the case, patterns, evaluation, the learning loop, the glossary).
- **AI wording:** optional, via Groq or xAI Grok, with a guardrail that drops answers citing IDs or codes not in the facts.
- **Code:** `backend/app/llm/assistant.py` and `backend/app/llm/client.py`; `frontend/components/Assistant.tsx`.

### 6. Fixes
- `db.init()` now adds missing columns to an existing SQLite database (an older DB crashed with "no such column: application.context").
- The Ring Simulator and live Attack Lab buttons show an error message instead of crashing the page.
- The landing page and Attack Lab no longer overflow on phones.
- `npm run build` now uses the stable webpack builder. The Turbopack production build failed on slow Google-font downloads; `npm run dev` still uses Turbopack.

## How to run

```bash
# backend (from backend/)
../.venv/Scripts/python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000     # Windows venv; Linux/mac: ../.venv/bin/python
# analyst console (from frontend/)
npm run dev                      # http://localhost:3000, proxies /api to http://127.0.0.1:8000 (BACKEND_URL to change)
# Kestrel partner site, connected to TrueID (from clients/kyc-homeloan/)
TRUEID_MODE=remote node server.js   # http://localhost:3013
```

The analyst key is in `backend/.secrets/analyst_key` (created on first start).

## Known limits on the development laptop

- **Models aren't built here:** the XGBoost model, OCR and face models need `scripts/build_all.sh` and large downloads. So `model: unavailable`, the challenger model can't train, and the connection check shows 10/12. Run the build on a machine with good bandwidth for 12/12.
- **Empty local database:** the learning and assistant screens say so plainly. Seed with the build script, or submit applications through the KYC flow or a partner site.
- **No LLM key here:** the assistant and summaries use templates until one is added (see `docs/ASSISTANT.md`).

## Left for the owner

1. Add a Groq or xAI Grok key (`backend/.secrets/xai_api_key` or `groq_api_key`) if you want AI wording, then restart the backend.

4. Decide when to open a PR from `feature/kyc-only-replicas` to `main`. Don't do this without the owner's say-so.
