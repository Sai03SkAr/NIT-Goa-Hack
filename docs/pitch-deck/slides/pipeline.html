04

One pass from upload to decision. Capture the form with typing rhythm, the card, a selfie with a server-issued head-turn burst, consent and geo-tag. Seven checks run in parallel. A model ranks risk and SHAP explains it; a profile learnt from genuine applicants only catches fraud types the model never saw. The decision is an evidence policy: all 13 required checks must pass to approve. Analysts see everything with an audit trail; the learning loop proposes changes they approve; applicants get tips only for fixable issues.
