TrueID is built to plug into a bank’s existing journey: the bank keeps its website and calls TrueID server to server. It follows RBI V-CIP and the DPDP Act, with an audit trail that can’t be edited silently. We are upfront about the limits: synthetic data, mock registries, liveness that isn’t PAD-certified yet, and SynthID only through Google’s API. One idea throughout: trust no single check.
